生成AIを知る / AI用語集

生成AIことば辞典｜「プロンプト」からやさしく分かるAI用語集【あ〜ん・A〜Z】

生成AIを使い始めると、「プロンプト」「トークン」「コンテキスト」など、聞き慣れない言葉が出てきます。

でも、これらの言葉を全部覚えてからAIを使い始める必要はありません。

このページでは、難しい言葉を見かけたときに、

「つまり、簡単に言うと何？」

がすぐ分かるようにまとめました。

たとえば、

プロンプト ＝ AIへのお願い・指示

くらいに考えれば、最初は十分です。

専門的な説明よりも、初めて生成AIを使う人が意味をつかめることを優先しています。

まずは、この10語だけでも大丈夫

用語 やさしい言いかえ
AI 人のように情報を処理するコンピューター技術
生成AI 文章や画像などを新しく作るAI
プロンプト AIへのお願い・指示
LLM 文章を扱うことが得意な大規模AI
コンテキスト AIが今の会話で参考にしている前後の情報
トークン AIが文章を読むときの小さな単位
ハルシネーション AIの「もっともらしい間違い」
RAG 資料を探してからAIが答える仕組み
マルチモーダル 文字だけでなく画像や音声なども扱えること
エージェント 目的に向かって複数の作業を進めるAIの仕組み

この10語が分かるだけでも、生成AIの記事や説明はかなり読みやすくなります。

日本語・五十音から探す【あ〜ん】

あ

アカウント

やさしい言いかえ： サービスを使うための自分用の登録情報
ログインするときに使う利用者の登録情報です。メールアドレスやパスワードなどと結び付いています。

アシスタント

やさしい言いかえ： AIの相談相手・作業の手伝い役
質問に答えたり、文章を作ったり、情報整理を手伝ったりするAIを指すときに使われます。

アップロード

やさしい言いかえ： ファイルをAIへ渡すこと
画像、PDF、表計算ファイルなどをAIに読み込ませる操作です。

い

依頼

やさしい言いかえ： AIに「これをして」と頼むこと
生成AIでは、難しい命令文でなくても普通の言葉で頼めます。

意図

やさしい言いかえ： 本当にしてほしいこと
同じ文章でも、目的が分かるとAIは答えを作りやすくなります。

入力

やさしい言いかえ： AIへ渡す情報
文章、画像、音声、ファイルなど、AIへ渡すもの全般を指します。

う

埋め込み（Embedding）

やさしい言いかえ： 文章や画像の意味を、AIが比べやすい数字に変えること
似た内容を探したり、関連する資料を見つけたりするときに使われる技術です。

え

エージェント（Agent）

やさしい言いかえ： 目的に向かって複数の作業を進めるAI
単に質問へ答えるだけでなく、必要な作業を考え、ツールなどを使いながら複数の手順を進める仕組みを指します。

お

応答

やさしい言いかえ： AIから返ってくる答え
英語では「Response」と呼ばれます。

音声入力

やさしい言いかえ： 話した言葉を文字にする入力方法
キーボードで文字を打つ代わりに、マイクへ話して文章を入力できます。

か

画像生成

やさしい言いかえ： 言葉から新しい画像を作ること
「夕焼けの海辺を水彩画風で」など、内容を伝えて画像を作らせる使い方です。

会話履歴

やさしい言いかえ： これまでAIと話した内容の記録
過去のチャットや、同じ会話の中で交わした内容を指します。

き

機械学習

やさしい言いかえ： たくさんのデータからコンピューターが特徴やパターンを学ぶ技術
現在のAIを支える代表的な技術の一つです。

教師あり学習

やさしい言いかえ： 正解例を見せながらAIに学ばせる方法
「この画像は猫」「このメールは迷惑メール」のように、答え付きのデータから学習します。

く

クエリ（Query）

やさしい言いかえ： 検索やAIに投げる質問
検索システムへ入力する言葉や問い合わせ内容を指します。

クラウド

やさしい言いかえ： インターネットの向こう側にあるコンピューターを使う仕組み
自分のパソコンだけで処理せず、インターネット経由でサービスを利用する形です。

け

検索拡張生成（RAG）

やさしい言いかえ： 必要な資料を探してからAIが答える仕組み
AIの記憶だけに頼らず、文書やデータベースなどから関連情報を探して回答へ利用します。

検証

やさしい言いかえ： AIの答えが本当に正しいか確かめること
重要な数字、制度、日付などは、AIの回答だけで決めず確認することが大切です。

こ

コンテキスト（Context）

やさしい言いかえ： AIがいま参考にしている前後の情報
現在の質問だけでなく、その前の会話や渡した資料なども含めて「文脈」と呼びます。

コーディング支援

やさしい言いかえ： プログラム作りをAIに手伝ってもらうこと
コードの作成、修正、説明、エラー調査などをAIに補助してもらう使い方です。

さ

再生成

やさしい言いかえ： AIにもう一度別の答えを作ってもらうこと
最初の答えが気に入らないときに、内容を変えて出し直してもらいます。

サンプリング

やさしい言いかえ： AIが次に使う言葉の候補から選ぶ仕組み
生成AIが毎回まったく同じ文章にならない理由の一つです。

し

自然言語処理（NLP）

やさしい言いかえ： 人が使う言葉をコンピューターで扱う技術
文章の意味を読み取ったり、翻訳したり、文章を作ったりする技術の総称です。

システムプロンプト

やさしい言いかえ： AIの基本的な役割やルールを決める指示
通常の質問よりも土台になる指示として使われます。

す

推論

やさしい言いかえ： 情報から考えて答えを出すこと
AIが与えられた情報を使って、答えや判断材料を作る処理を指します。

スレッド

やさしい言いかえ： ひと続きの会話
1つのテーマについて続けてやり取りするチャットのまとまりです。

せ

生成AI

やさしい言いかえ： 文章・画像・音声などを新しく作るAI
質問に答えるだけでなく、文章作成、画像生成、要約、翻訳など幅広い作業ができます。

そ

ソース

やさしい言いかえ： 情報の出どころ
AIの答えが何を根拠にしているのか確認するときに大切です。

ソースコード

やさしい言いかえ： コンピューターへ動きを指示するために書かれたプログラムの文章
AIを使って作成・修正することもできます。

た

タスク

やさしい言いかえ： AIにやってもらう一つの作業
要約、翻訳、文章作成、調査など、一つ一つの仕事をタスクと呼びます。

ち

チャット

やさしい言いかえ： AIとの会話
文章や音声で質問と回答をやり取りする形式です。

チャットボット

やさしい言いかえ： 会話形式で答えるコンピューターサービス
生成AIを使ったものもあれば、あらかじめ決められた答えだけを返すものもあります。

つ

ツール

やさしい言いかえ： AIが作業するときに使う道具
検索、計算、ファイル操作、予定管理など、AI本体とは別の機能を指すことがあります。

て

データセット

やさしい言いかえ： 学習や分析に使うデータの集まり
文章、画像、表などをまとめたものです。

テキスト生成

やさしい言いかえ： AIが文章を作ること
メール、説明文、要約、記事の下書きなどを作る処理です。

と

トークン（Token）

やさしい言いかえ： AIが文章を読むときの小さな単位
1文字や1単語と完全に同じではなく、AIが文章を細かく分けて扱う単位です。

な

ナレッジ

やさしい言いかえ： AIに参考にさせる知識や情報
社内資料、説明書、過去の文書などを指すことがあります。

ナレッジベース

やさしい言いかえ： 参考情報をまとめて置いておく場所
AIが回答するときに参照する資料の集まりとして使われます。

に

ニューラルネットワーク

やさしい言いかえ： 人の脳の仕組みを参考にしたAIの計算方法
現在の多くのAIを支える基本技術の一つです。

ぬ

抜き出し

やさしい言いかえ： 必要な部分だけ取り出すこと
長い文章から日付、金額、名前、重要項目だけを取り出すようAIへ頼む使い方です。

ね

ネット検索

やさしい言いかえ： インターネットから新しい情報を探すこと
AIが検索機能を使える場合、学習済みの知識だけでなく現在の情報を調べられることがあります。

の

ノイズ

やさしい言いかえ： 必要な情報を分かりにくくする余計な情報
データや文章に不要な情報が多いと、AIの判断や検索精度へ影響することがあります。

は

ハルシネーション（Hallucination）

やさしい言いかえ： AIの「もっともらしい間違い」
生成AIは、分からないことでも自然な文章で誤った内容を答えることがあります。重要な情報は必ず確認します。

パラメータ

やさしい言いかえ： AIが学習の中で調整した大量の内部数値
AIモデルの規模を説明するときに「○○億パラメータ」などと表現されることがあります。

ひ

評価

やさしい言いかえ： AIの答えや性能を確かめること
正確さ、分かりやすさ、速度など、目的に応じてAIの出来を確認します。

ふ

ファインチューニング

やさしい言いかえ： 既に学習したAIを、特定の用途向けに追加調整すること
一からAIを作るのではなく、既存モデルを特定の仕事に合わせます。

プロンプト（Prompt）

やさしい言いかえ： AIへのお願い・指示
生成AIへ入力する質問や依頼内容です。

たとえば、

この文章を、小学生にも分かる言葉に直してください。

これも立派なプロンプトです。

難しい命令文を書く必要はありません。「AIに何をしてほしいかを伝える文章」と考えると分かりやすいです。

へ

ベクトル

やさしい言いかえ： AIが意味や特徴を比べるために使う数字の並び
文章や画像の「似ている・似ていない」を計算するときなどに使われます。

変換

やさしい言いかえ： 情報を別の形へ直すこと
文章を表にする、音声を文字にする、日本語を英語にする、といった処理です。

ほ

補足指示

やさしい言いかえ： AIの答えを直すために後から追加するお願い
最初から完璧な指示を書かなくても、「もっと短く」「表にして」と追加で頼めます。

ま

マークダウン（Markdown）

やさしい言いかえ： 記号を使って見出しや箇条書きを表す書き方
AIが文章を整理して出力するときによく使われます。

マルチモーダル

やさしい言いかえ： 文字だけでなく、画像・音声など複数の種類の情報を扱えること
画像を見せて質問したり、音声で会話したりできるAIがこれに当たります。

み

見出し生成

やさしい言いかえ： 内容に合うタイトルや小見出しをAIに考えてもらうこと
記事、資料、メールなどを整理するときに使いやすい方法です。

む

無効化

やさしい言いかえ： 機能を使わない設定にすること
AIサービスの設定画面などで、特定の機能をオフにするときに使われます。

め

メモリ（Memory）

やさしい言いかえ： AIが次の会話にも役立てるために覚えておく情報
サービスによって、保存される内容や仕組みは異なります。

も

モデル（Model）

やさしい言いかえ： 学習を終えて、質問への回答などに使えるAI本体
同じサービスでも、性能や得意分野の異なる複数のモデルが使われることがあります。

や

やり取り

やさしい言いかえ： AIと質問・回答を続けること
一度で完璧な答えを求めず、追加で頼みながら整えていくのが生成AIの使いやすい方法です。

ゆ

ユーザー（User）

やさしい言いかえ： AIを使っている人
サービスの利用者を指します。

よ

要約

やさしい言いかえ： 長い内容を短くまとめること
文章、議事録、資料などの重要な部分だけを読みやすく整理します。

ら

ラージランゲージモデル（Large Language Model / LLM）

やさしい言いかえ： 大量の文章を学び、言葉を扱うことが得意な大規模AI
ChatGPTのような生成AIを理解するときによく出てくる言葉です。

り

リマインダー

やさしい言いかえ： あとで知らせてもらう機能
「明日の朝9時に教えて」のように、決めた時間に通知してもらう仕組みを指します。

履歴

やさしい言いかえ： これまで行った操作や会話の記録
過去のチャットを見返すときなどに使われます。

る

ルール

やさしい言いかえ： AIに守ってほしい決まり
「必ず日本語で答える」「分からないことは推測しない」などの条件を指示できます。

れ

レスポンス（Response）

やさしい言いかえ： AIから返ってくる答え
日本語では「応答」「回答」と考えれば大丈夫です。

ろ

ローカルAI / ローカルモデル

やさしい言いかえ： インターネット上のサービスではなく、自分のパソコンなどで動かすAI
必要な性能や設定はモデルによって大きく異なります。

わ

ワークフロー（Workflow）

やさしい言いかえ： 仕事の流れ・作業手順
たとえば「資料を読む → 要約する → 表にまとめる」という一連の流れです。

を

生成AIの基本用語として「を」から始まる一般的な用語は多くありません。
無理に専門用語を覚える必要はありません。

ん

日本語では「ん」から始まる言葉がほとんどないため、この用語集でも基本用語はありません。

英字から探す【A〜Z】

英語の略語や技術用語も、まずは日本語の意味だけ分かれば十分です。

A

AI（Artificial Intelligence）

やさしい言いかえ： 人の知的な作業をコンピューターで行う技術
日本語では「人工知能」と呼ばれます。

Agent

読み方： エージェント
やさしい言いかえ： 目的に向かって複数の作業を進めるAI

B

Benchmark

読み方： ベンチマーク
やさしい言いかえ： AIの性能を比べるための共通テスト

Bias

読み方： バイアス
やさしい言いかえ： データや答えに含まれる偏り

C

Chatbot

読み方： チャットボット
やさしい言いかえ： 会話形式で答えるコンピューター

Context

読み方： コンテキスト
やさしい言いかえ： AIが今の回答で参考にしている前後の情報

D

Dataset

読み方： データセット
やさしい言いかえ： 学習や分析に使うデータの集まり

Deep Learning

読み方： ディープラーニング
やさしい言いかえ： 多くの層を持つニューラルネットワークを使った機械学習

E

Embedding

読み方： エンベディング
やさしい言いかえ： 言葉や画像の意味を、比べやすい数字に変えること

F

Fine-tuning

読み方： ファインチューニング
やさしい言いかえ： 既存のAIを特定用途向けに追加調整すること

Foundation Model

読み方： ファウンデーションモデル
やさしい言いかえ： さまざまな用途の土台として使える大規模なAIモデル

G

Generative AI

読み方： ジェネレーティブAI
やさしい言いかえ： 文章や画像などを新しく作るAI

Grounding

読み方： グラウンディング
やさしい言いかえ： AIの回答を資料や事実に結び付けること

H

Hallucination

読み方： ハルシネーション
やさしい言いかえ： AIの「もっともらしい間違い」

I

Inference

読み方： インファレンス
やさしい言いかえ： 学習済みAIが実際に答えを作る処理

Instruction

読み方： インストラクション
やさしい言いかえ： AIへの指示

J

JSON

読み方： ジェイソン
やさしい言いかえ： コンピューター同士で情報を渡しやすい、決まった形のデータ
AIに「JSON形式で出して」と頼むと、システムへ取り込みやすい形に整理できることがあります。

K

Knowledge Base

読み方： ナレッジベース
やさしい言いかえ： AIなどが参考にする情報をまとめた場所

L

LLM（Large Language Model）

読み方： エル・エル・エム
やさしい言いかえ： 大量の文章を学び、言葉を扱うことが得意な大規模AI

M

Model

読み方： モデル
やさしい言いかえ： 学習を終えて実際の回答に使われるAI本体

Multimodal

読み方： マルチモーダル
やさしい言いかえ： 文字、画像、音声など複数種類の情報を扱えること

N

NLP（Natural Language Processing）

読み方： エヌ・エル・ピー
やさしい言いかえ： 人が使う言葉をコンピューターで扱う技術

Neural Network

読み方： ニューラルネットワーク
やさしい言いかえ： 人の脳の仕組みを参考にしたAIの計算方法

O

Output

読み方： アウトプット
やさしい言いかえ： AIが出した答えや結果

P

Prompt

読み方： プロンプト
やさしい言いかえ： AIへのお願い・指示

Parameter

読み方： パラメータ
やさしい言いかえ： AIが学習で調整した内部の数値

Q

Query

読み方： クエリ
やさしい言いかえ： 検索やAIへ投げる質問・問い合わせ

R

RAG（Retrieval-Augmented Generation）

読み方： ラグ
やさしい言いかえ： 必要な資料を探してからAIが答える仕組み

Reasoning

読み方： リーズニング
やさしい言いかえ： 情報をもとに考えて答えを組み立てること

S

System Prompt

読み方： システムプロンプト
やさしい言いかえ： AIの役割や基本ルールを決める指示

Summarization

読み方： サマライゼーション
やさしい言いかえ： 長い内容を短くまとめること

T

Token

読み方： トークン
やさしい言いかえ： AIが文章を読むときの小さな単位

Temperature

読み方： テンパラチャー
やさしい言いかえ： AIの答えのばらつき具合を調整する設定
一般に、設定が低いと安定した答え、高いと変化のある答えになりやすくなります。

Transformer

読み方： トランスフォーマー
やさしい言いかえ： 現在の多くの文章AIの土台になっている仕組み

U

User Prompt

読み方： ユーザープロンプト
やさしい言いかえ： 利用者がAIへ入力した質問やお願い

V

Vector

読み方： ベクトル
やさしい言いかえ： 意味や特徴を比べるための数字の並び

Vector Database

読み方： ベクトルデータベース
やさしい言いかえ： 意味が似た情報を探しやすく保存する仕組み

W

Workflow

読み方： ワークフロー
やさしい言いかえ： 仕事の流れ・作業手順

X

XAI（Explainable AI）

読み方： エックス・エー・アイ
やさしい言いかえ： AIがなぜその答えや判断を出したのか、人が理解しやすくする考え方や技術

Y

YAML

読み方： ヤメル / ヤムル
やさしい言いかえ： 設定内容などを人にも読みやすく書くためのデータ形式
AIを使ったプログラム開発や設定ファイルで見かけることがあります。

Z

Zero-shot

読み方： ゼロショット
やさしい言いかえ： お手本を見せず、指示だけでAIにやってもらう方法
たとえば文章例を一つも渡さず、「この文章を丁寧なメールに直して」と頼む使い方です。

「プロンプト」は難しい言葉ではありません

生成AIを初めて使う人が、最初につまずきやすい言葉の一つがプロンプトです。

しかし、プロンプトを難しく考える必要はありません。

プロンプト ＝ AIへのお願い・指示

です。

たとえば、

今日の夕飯を3つ考えて。

このメールを丁寧にして。

この写真に何が写っているか説明して。

この資料を3行でまとめて。

これらはすべてプロンプトです。

「良いプロンプトを書く技術」もありますが、最初から勉強しなくても大丈夫です。まずは普通の言葉で頼んで、足りなければ後から言い足すだけでも十分に使えます。

分からない言葉は、そのままAIに聞いてもいい

この用語集を全部覚える必要はありません。

AIの記事や画面で分からない言葉を見つけたら、AI自身に、

「トークンって何？ 小学生にも分かるように説明して」

「RAGを専門用語を使わずに説明して」

と聞くこともできます。

生成AIを使うために、生成AIの専門家になる必要はありません。

分からない言葉が出てきたら、その都度調べる。
それくらいから始めて十分です。

RETUNE WORKS AI JOURNALの考え方

  • プロンプト → AIへのお願い・指示
  • リマインダー → あとで知らせてもらう機能
  • ハルシネーション → AIのもっともらしい間違い
